# 平台内容 Playbook（模式③）

生成时严格按对应结构输出；文风必须贴合品牌调性字段。

## xiaohongshu 小红书

```
### 爆款标题（5 选 1 使用，其余备用）
- 每个 ≤20 字，含数字/悬念/情绪词，可用 emoji，禁止标题党到与正文不符

### 正文
- 开头黄金 3 秒：第一句制造钩子（反差、提问、利益点），决定完读率
- 主体：故事或干货清单（3-5 个要点，短句 + emoji 分行，口语化）
- 产品植入：1 段，场景化带出（"我一般用__解决"），说明差异化卖点 1-2 条，不堆参数
- CTA：引导互动（收藏/评论提问/"评论区扣1"）或行动（戳主页/链接）

### 热门标签
- 8 个：2 个热点标签 + 3 个品类/行业标签 + 2 个场景人群标签 + 1 个品牌自造标签
```
算法取向：完读与互动优先；避免硬广词（最低价、官方授权等除非属实）、避免站外导流话术。

## tiktok TikTok / 抖音 / Reels 短视频脚本

```
### 视频标题（1 条 + 2 备选）
### 前 3 秒 Hook
- 具体台词 + 画面提示；用冲突/悬念/利益承诺留人
### 分镜脚本（4-6 个镜头）
| 镜头 | 画面 | 旁白/台词 | 时长 |
- 节奏：每镜 ≤5 秒；第 2-3 镜埋一个"再看一遍"细节
### 产品展示镜头
- 特写 + 一句卖点台词（数字化的卖点更有说服力：省了X%、快X倍）
### 结尾 CTA
- 口播 + 字幕双通道；关注/评论/点击主页三选一，别贪多
```
附带：BGM 建议（描述风格即可，不指定具体版权曲目）、发布话题标签 3-5 个。
海外版（TikTok/Reels）台词用英文 + 本地化梗；国内版（抖音）用中文。

## linkedin LinkedIn 商业洞察文章

```
### Headline
- 观点式而非标题党，英文或中英双语（面向海外市场时优先英文）
### 1. 行业趋势
- 以今日热点为引子，给出行业层面的判断
### 2. 用户痛点
- 目标客户视角，具体到工作场景
### 3. 解决方案
- 方法论框架（3 步或 3 点），产品作为方案中的自然一环
### 4. 企业价值
- 差异化卖点收束 + 软性 CTA（评论交流/关注获取完整版）
```
风格：第一人称专业口吻，短段落，每段 ≤3 行；开头 2 行决定点击"see more"，必须直接给观点或反直觉数据；避免 hashtag 堆砌（3-5 个放文末）。

## wechat 微信公众号

```
标题（主标题+副标题）→ 导语（热点引入 ≤80 字）→ 正文（小标题分 3-4 节，
金句可加粗，产品植入放在第 3 节的方案部分）→ 结尾引导（在看/星标/留言）。
排版提示：单段 ≤4 行，重点句标记出来方便编辑器加粗。
```

## instagram / twitter（通用规范）

- Instagram：英文 caption 前 125 字符内完成钩子（截断线）+ 15-30 个混排 hashtag + Reels 版复用 tiktok playbook 分镜。
- Twitter/X：一条主推文 ≤280 字符钩子 + 3-6 条 thread 展开观点 + 结尾 CTA；转发型借势优先引用热点原帖语气。
