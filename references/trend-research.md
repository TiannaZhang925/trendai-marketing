# 热点检索策略（模式②）

目标：拿到「今天」真实可查的热点。一律使用当前年份/近期时间词查询；每个来源 1-2 次 WebSearch 即可，总量控制在 4-6 次搜索。

## 查询配方（按品牌资料的语言与平台取向组合，不必全用）

| 数据源 | 查询示例 |
| --- | --- |
| 微博热搜 | `微博热搜 今日 榜单 {年}`；`微博 热搜 第一 {年}月` |
| 抖音热点 | `抖音热榜 今日 热点 {年}`；`抖音 热门话题 {月}` |
| TikTok Trending | `TikTok trending hashtags this week {年}`；`TikTok trending sounds {月}` |
| Google Trends | `Google Trends trending searches today {年}`；`{行业关键词} rising trend Google Trends` |
| Reddit | `site:reddit.com r/all trending {话题域}`；`Reddit viral {行业} {年}` |
| 行业新闻 | `{品牌行业} 新闻 本周`；`{行业} 趋势 报告 {年}` |
| AI 资讯 | `AI 发布 本周 新闻`；`AI 行业热点 {月} {年}` |

## 候选热点筛选标准

保留满足任一条的热点：
1. 与品牌行业直接相关；
2. 大众情绪强（共鸣/争议/怀旧/猎奇），可被任何品牌「借势」；
3. 与产品卖点存在嫁接点（效率、成本、出海、版权等）；
4. 处于上升期而非衰退期（搜索结果中出现频次近期明显增加）。

剔除：负面灾难/事故类、政治敏感、纯娱乐绯闻（除非调性年轻且无风险）、品牌无法安全关联的争议话题。

## 分析字段口径

- 热度指数：跨来源相对排序估算（0-100），非精确读数；有榜单名次时以名次换算。
- 增长趋势：上升/爆发/平台期/衰退，依据时间线索（首次出现时间、讨论量变化描述）。
- 用户情绪：正面 / 中性 / 热议 / 争议。争议类须标注风险提示。
- 适合行业：列 2-5 个。
- 商业关联度：品牌能否自然参与叙事（区别于「火不火」，衡量「能不能借」）。

## 诚实性要求

- 输出顶部注明：数据来自实时网络搜索，时间为本次会话时刻，热度为估算排序。
- 搜索结果稀疏、过时或互相矛盾时，如实说明并降级为「参考方向」；不得编造具体阅读量、播放量数字。
- 如需精确数据（供客户汇报等场景），建议用户接入官方热榜 API 或数据平台。
